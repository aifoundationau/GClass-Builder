PART 1: ARCHITECTURE & SUPERADMIN ACCOUNTS
--------------------------------------------------------------------------------
The security model operates on a unified multi-tenant architecture under the shared
Firebase project 'ai-foundation-firebase'.

1. SuperAdmin (System Owner)
   SuperAdmin rights are anchored strictly to verified owner accounts at sign-in.
   SuperAdmin is never assigned through roles; it automatically holds every permission
   and cannot be locked out or revoked.

   Owner UIDs:
     - ZK79FRQoVlYhsgvMibhi81dRUWj2
     - L5euSJAfNKdDOX6mT0qmrCGjUA53

   Owner Verified Emails:
     - davidrobertson.info@gmail.com
     - support@aifoundation.net.au

2. Tenant Isolation & Collection Names
   All RBAC collections for this application carry the 'gcoursebuilder_' prefix to
   prevent collision with sibling apps sharing the database:
     - Roles Collection: /gcoursebuilder_roles/{roleKey}
     - Assignments Collection: /gcoursebuilder_role_assignments/{email}

3. Default User Role
   Any authenticated Google user without an explicit assignment document defaults to
   the 'supporter' role with read-only access to course catalog entries.

PART 2: SYSTEM ROLES (12 ROLES HIERARCHY)
--------------------------------------------------------------------------------
Ranked from highest authority (Level 100) to baseline (Level 10):

1. superadmin (Level 100)
   - Unrestricted access across every system, including role permissions.
   - Always holds all 24 permissions.
   - Non-assignable via assignments collection (strictly reserved for system owners).

2. chiefadmin (Level 95)
   - Senior administrative authority ahead of Chancellor.
   - Holds full operational authority and all 24 system permissions by baseline.
   - Can configure role permissions for all other roles (superadmin role remains locked).
   - Can assign all other roles to verified user emails (cannot give the superadmin role).
   - Assignable via /gcoursebuilder_role_assignments/{email}.

3. administration (Level 92)
   - Admissions office, student records, user accounts, and campus content management.

4. chancellor (Level 90)
   - Institutional oversight of academic standing, admissions, and finance.

5. president (Level 85)
   - Executive leadership across admissions decisions, finance approvals, and campus operations.

6. ceo (Level 80)
   - Executive operations, admissions decisions, and budget approvals.

7. coo (Level 75)
   - Campus operations: events, calendar, staff communications, and data sync.

8. cfo (Level 70)
   - Finance leadership: ledgers, approvals, and emergency fund disbursement.

9. accounting (Level 60)
   - Day-to-day finance: financial ledgers, approvals, and student emergency tokens.

10. teacher (Level 40)
    - Builds and publishes courses in Google Classroom and grades student assignments.

11. student (Level 30)
    - Enrolled learner: views courses, grades, transcripts, and campus events.

12. supporter (Level 10)
    - Default baseline for all new sign-ins: can inspect course outlines.

Assignable Roles:
  chiefadmin, administration, chancellor, president, ceo, coo, cfo, accounting,
  teacher, student, supporter (11 assignable roles; superadmin is strictly system owner).

Legacy Role Normalization Aliases:
  - 'super admin', 'super_admin' -> superadmin
  - 'chief admin', 'chief_admin' -> chiefadmin
  - 'admin staff', 'admin', 'administrator', 'school_admin' -> administration
  - 'financial team', 'finance' -> accounting
  - 'instructor' -> teacher

PART 5: DATA CONTRACTS & VALIDATION SCHEMAS
--------------------------------------------------------------------------------

1. Role Definition Document: /gcoursebuilder_roles/{roleId}
   - Document ID: Must be one of the 12 valid role keys (superadmin .. supporter).
   - Strict Allowed Keys: ['roleName', 'permissions', 'updatedAt', 'updatedBy']
   - Constraints:
     * roleName: string between 1 and 60 characters.
     * permissions: list of valid unique permission keys (no duplicates, no unknown strings).
     * superadmin role doc must always retain all 24 permission keys.
     * updatedAt: must match request.time (Firestore server timestamp).
     * updatedBy: must equal request.auth.uid.
   - Permissions:
     * Read: Authenticated users.
     * Write (create, update): SuperAdmin, or users holding roles.manage (such as Chief Admin) for all roles EXCEPT superadmin.
     * Delete: Disallowed (allow delete: if false).

2. Role Assignment Document: /gcoursebuilder_role_assignments/{email}
   - Document ID: Lower-case, sanitized recipient email address.
   - Strict Allowed Keys: ['email', 'role', 'assignedAt', 'assignedBy']
   - Constraints:
     * email: lower-case string matching valid email regex.
     * role: must be in assignable roles list (superadmin cannot be assigned by anyone).
     * assignedAt: must match request.time.
     * assignedBy: must equal request.auth.uid.
   - Permissions:
     * Read: SuperAdmin, users holding 'users.manage' permission (such as Chief Admin), or the user themselves (if email matches verified Google auth email).
     * Write (create, update, delete): SuperAdmin or users holding 'users.manage' permission (such as Chief Admin).

PART 6: PRODUCTION FIRESTORE SECURITY RULES (VERBATIM)
--------------------------------------------------------------------------------
rules_version = '2';

// One set of rules for every app sharing ai-foundation-firebase (AI Foundation, the LMS, token-kit apps,
// GCourse Builder and others). Deploy only from the AI Foundation folder:
//   firebase deploy --only firestore:rules --project ai-foundation-firebase
// An app's own collections carry its tag as a prefix (aifoundation_token_checkouts, gcoursebuilder_roles), so no
// two apps share a collection by accident. The SuperAdmin is the owner in every app (isSuperAdmin, from the sign-in);
// every other role and permission belongs to one app, in its own collections. List each new collection in
// isProtectedCollection, with its own rules.

service cloud.firestore {
  match /databases/{database}/documents {

    function isAuthenticated() {
      return request.auth != null;
    }

    function isOwner(userId) {
      return isAuthenticated() && request.auth.uid == userId;
    }

    // SuperAdmins: matched by UID, or by email only when Google has verified that email
    function isSuperAdmin() {
      return isAuthenticated() && (
        request.auth.uid in ['ZK79FRQoVlYhsgvMibhi81dRUWj2', 'L5euSJAfNKdDOX6mT0qmrCGjUA53'] ||
        (request.auth.token.email_verified == true && request.auth.token.email in [
          'support@aifoundation.net.au',
          'davidrobertson.info@gmail.com'
        ])
      );
    }

    // Admins: SuperAdmins, or users whose profile role was set to admin by a SuperAdmin / the server
    function isAdmin() {
      return isSuperAdmin() || (
        isAuthenticated() &&
        exists(/databases/$(database)/documents/users/$(request.auth.uid)) &&
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.get('role', '') in ['admin', 'super_admin', 'superadmin', 'chiefadmin']
      );
    }

    // Collections holding PII or authorization data. Excluded from the catch-all rule below,
    // because Firestore rules are OR'd and a broad match would otherwise override these.
    function isProtectedCollection(name) {
      return name in ['users', 'transactions', 'stripe_transactions', 'paypal_transactions',
                      'chat_interactions', 'system_settings', 'admins', 'content',
                      'token_ledger', 'aifoundation_token_checkouts', 'token_checkouts',
                      'gcoursebuilder_roles', 'gcoursebuilder_role_assignments'];
    }

    // Profile fields that grant privileges or hold value; users can never set or change these themselves.
    // token_balance is the token balance every app shares: only servers change it (service account)
    function privilegedFields() {
      return ['role', 'status', 'classification', 'isSuperAdmin', 'isAdmin', 'tags',
              'token_balance', 'token_balance_updated_at'];
    }

    // AI Foundation Content (Articles, Projects, Tech, Community)
    // Anyone can read public content; only admins can publish, edit or delete
    match /content/{docId} {
      allow read: if true;
      allow write: if isAdmin();
    }

    // User Profiles (PII): readable by the owner and admins only
    match /users/{userId} {
      allow read: if isOwner(userId) || isAdmin();
      allow create: if isSuperAdmin() || (
        isOwner(userId) &&
        request.resource.data.get('role', 'supporter') == 'supporter' &&
        request.resource.data.get('status', 'supporter') == 'supporter' &&
        request.resource.data.get('isSuperAdmin', false) == false &&
        request.resource.data.get('isAdmin', false) == false &&
        request.resource.data.get('token_balance', 0) == 0 &&
        !request.resource.data.keys().hasAny(['tags', 'token_balance_updated_at'])
      );
      allow update: if isSuperAdmin() || (
        isOwner(userId) &&
        !request.resource.data.diff(resource.data).affectedKeys().hasAny(privilegedFields())
      );
      allow delete: if isSuperAdmin();
    }

    // Transactions / Checkout Records (PII): written only by the server (service account)
    match /{txCollection}/{txId} {
      allow read: if txCollection in ['stripe_transactions', 'paypal_transactions'] && isAdmin();
      allow write: if false;
    }
    match /transactions/{txId} {
      allow read: if isAdmin();
      allow write: if false;
    }

    // Supporter Chat & Administrative Messaging (Multi-Tenant)
    // - Supporters can only send as themselves
    // - SuperAdmin can read all messages from ALL tenants
    // - Normal supporters can ONLY read their own messages
    // - Only SuperAdmin can delete or modify records
    match /chat_interactions/{msgId} {
      allow create: if isAuthenticated() && request.resource.data.senderUid == request.auth.uid;
      allow read: if isSuperAdmin() || (
        isAuthenticated() && (
          request.auth.uid == resource.data.senderUid ||
          request.auth.uid == resource.data.recipientUid
        )
      );
      allow update, delete: if isSuperAdmin();
    }

    // Token ledger: one entry per change to a token balance (purchase, grant or spend). Users read their own entries;
    // only servers write them (service account), in the same commit as the balance change
    match /token_ledger/{entryId} {
      allow read: if (isAuthenticated() && resource.data.uid == request.auth.uid) || isAdmin();
      allow write: if false;
    }

    // Token checkouts not paid yet (Buy Tokens): server only, readable by the owner and admins
    match /aifoundation_token_checkouts/{userId} {
      allow read: if isOwner(userId) || isAdmin();
      allow write: if false;
    }
    // The same for the owner's other apps (token-kit), one document per app and user: {appTag}_{uid}
    match /token_checkouts/{docId} {
      allow read: if (isAuthenticated() && resource.data.uid == request.auth.uid) || isAdmin();
      allow write: if false;
    }

    // Admin email lists used for authorization (PII)
    match /system_settings/{docId} {
      allow read, write: if isSuperAdmin();
    }
    match /admins/{docId} {
      allow read, write: if isSuperAdmin();
    }

    // GCourse Builder (tag gcoursebuilder): role-based access control, from the app's firestore.rules (which its
    // emulator tests use). Its profiles follow the users rules above.
    // The SuperAdmin is the owner, as in every app: isSuperAdmin() above, from the sign-in's UID or verified email.
    // Every other role is the app's own: the role the SuperAdmin gave the person's verified email in
    // gcoursebuilder_role_assignments, else supporter. What a role may do is the permissions list in
    // gcoursebuilder_roles/{role}. gcbRoleKeys() and gcbPermissionKeys() must match the app's src/rbac/permissions.js.
    function gcbHasVerifiedEmail() {
      return request.auth.token.get('email', '') != ''
        && request.auth.token.get('email_verified', false) == true;
    }

    // Only call after gcbHasVerifiedEmail()
    function gcbAssignmentPath() {
      return /databases/$(database)/documents/gcoursebuilder_role_assignments/$(request.auth.token.email.lower());
    }

    function gcbRoleGrants(role, perm) {
      return exists(/databases/$(database)/documents/gcoursebuilder_roles/$(role))
        && perm in get(/databases/$(database)/documents/gcoursebuilder_roles/$(role)).data.permissions;
    }

    // The role assigned to the verified email, else supporter
    function gcbAssignedRoleGrants(perm) {
      return (gcbHasVerifiedEmail() && exists(gcbAssignmentPath())
          && gcbRoleGrants(get(gcbAssignmentPath()).data.role, perm))
        || (!(gcbHasVerifiedEmail() && exists(gcbAssignmentPath())) && gcbRoleGrants('supporter', perm));
    }

    // True when the signed-in user's role includes perm. The SuperAdmin holds every permission
    function gcbHasPermission(perm) {
      return isAuthenticated() && (isSuperAdmin() || gcbAssignedRoleGrants(perm));
    }

    function gcbRoleKeys() {
      return ['superadmin', 'chiefadmin', 'administration', 'chancellor', 'president', 'ceo', 'coo', 'cfo', 'accounting',
              'teacher', 'student', 'supporter'];
    }

    function gcbPermissionKeys() {
      return [
        'courses.view', 'courses.create', 'courses.publish', 'grades.view', 'grades.edit', 'classroom.manage',
        'applications.view', 'applications.review', 'applications.export', 'students.manage',
        'finance.view', 'finance.approve', 'tokens.manage', 'events.manage', 'calendar.manage',
        'ai.customize', 'faqs.edit', 'messaging.staff', 'telemetry.view',
        'users.manage', 'roles.manage', 'sheets.sync', 'api_keys.manage', 'campus_metrics.manage'
      ];
    }

    // { roleName, permissions, updatedAt, updatedBy }, stamped by the writer at the server's time.
    // The superadmin role must keep every permission, so it can't be locked out
    function gcbIsValidRoleDoc(roleId) {
      let data = request.resource.data;
      return roleId in gcbRoleKeys()
        && data.keys().hasAll(['roleName', 'permissions', 'updatedAt', 'updatedBy'])
        && data.keys().hasOnly(['roleName', 'permissions', 'updatedAt', 'updatedBy'])
        && data.roleName is string && data.roleName.size() > 0 && data.roleName.size() <= 60
        && data.permissions is list
        && data.permissions.size() <= gcbPermissionKeys().size()
        && data.permissions.toSet().size() == data.permissions.size()
        && data.permissions.hasOnly(gcbPermissionKeys())
        && (roleId != 'superadmin' || data.permissions.hasAll(gcbPermissionKeys()))
        && data.updatedAt == request.time
        && data.updatedBy == request.auth.uid;
    }

    // { email, role, assignedAt, assignedBy } at the lower-case email. Superadmin is never assigned: it is the owner
    function gcbIsValidAssignment(email) {
      let data = request.resource.data;
      return email == email.lower()
        && email.matches('[^@ /]+@[^@ /]+[.][^@ /]+')
        && data.keys().hasAll(['email', 'role', 'assignedAt', 'assignedBy'])
        && data.keys().hasOnly(['email', 'role', 'assignedAt', 'assignedBy'])
        && data.email == email
        && data.role in gcbRoleKeys()
        && data.role != 'superadmin'
        && data.assignedAt == request.time
        && data.assignedBy == request.auth.uid;
    }

    // Role permissions: readable when signed in, written by SuperAdmin, or by users holding roles.manage
    // (such as Chief Admin) for all roles except superadmin.
    match /gcoursebuilder_roles/{roleId} {
      allow read: if isAuthenticated();
      allow create, update: if (isSuperAdmin() || (gcbHasPermission('roles.manage') && roleId != 'superadmin'))
        && gcbIsValidRoleDoc(roleId);
      allow delete: if false;
    }

    // Roles given to email addresses: people can read their own; SuperAdmin and users with users.manage
    // (such as Chief Admin) can assign all roles except superadmin.
    match /gcoursebuilder_role_assignments/{email} {
      allow read: if isSuperAdmin()
        || gcbHasPermission('users.manage')
        || (isAuthenticated() && gcbHasVerifiedEmail() && request.auth.token.email.lower() == email);
      allow create, update: if (isSuperAdmin() || gcbHasPermission('users.manage'))
        && gcbIsValidAssignment(email);
      allow delete: if isSuperAdmin() || gcbHasPermission('users.manage');
    }

    // Fallback for other tenants' collections (unchanged behaviour),
    // excluding the protected collections above
    match /{collectionName}/{document=**} {
      allow read: if !isProtectedCollection(collectionName);
      allow write: if isAuthenticated() && !isProtectedCollection(collectionName);
    }
  }
}
